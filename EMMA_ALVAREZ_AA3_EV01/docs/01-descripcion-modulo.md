# Descripción del módulo

## Proyecto
Sistema de Inventario para Tiendas.

## Evidencia
GA7-220501096-AA3-EV01.

## Framework seleccionado
Spring Boot con Spring MVC y Thymeleaf.

## Objetivo
Desarrollar un módulo web sencillo que permita administrar los productos de una tienda.

## Funcionalidades
- Registrar producto.
- Consultar inventario.
- Buscar por nombre.
- Editar producto.
- Eliminar producto.
- Validar datos.

## Arquitectura
El proyecto utiliza una separación básica por responsabilidades:
- Modelo: `Producto`.
- Servicio: `ProductoService`.
- Controlador: `ProductoController`.
- Vista: páginas Thymeleaf.
