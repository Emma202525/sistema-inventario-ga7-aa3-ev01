# Historias de usuario

### HU-01
Como administrador de una tienda, quiero registrar productos para mantener actualizado el inventario.

### HU-02
Como usuario, quiero consultar los productos para conocer las existencias.

### HU-03
Como usuario, quiero buscar productos por nombre para encontrarlos rápidamente.

### HU-04
Como administrador, quiero actualizar productos para corregir o cambiar su información.

### HU-05
Como administrador, quiero eliminar productos que ya no se comercializan.
