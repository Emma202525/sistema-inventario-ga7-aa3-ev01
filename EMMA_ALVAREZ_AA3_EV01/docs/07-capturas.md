# Capturas recomendadas

Antes de entregar, tomar capturas de:
1. Proyecto abierto en el IDE.
2. Página principal/listado del inventario.
3. Formulario de registro.
4. Producto registrado.
5. Búsqueda.
6. Edición.
7. Eliminación.
8. Ejecución de `mvn clean test`.
9. Repositorio de GitHub.

Las capturas pueden anexarse si el instructor solicita evidencia visual.
