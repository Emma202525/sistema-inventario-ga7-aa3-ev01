# Casos de uso

### CU-01 Registrar producto
El usuario diligencia los datos de un producto y selecciona Guardar.

### CU-02 Consultar inventario
El usuario accede al módulo y visualiza los productos registrados.

### CU-03 Buscar producto
El usuario introduce el nombre o parte del nombre y consulta coincidencias.

### CU-04 Editar producto
El usuario selecciona Editar, modifica los datos y guarda los cambios.

### CU-05 Eliminar producto
El usuario selecciona Eliminar y confirma la operación.
